# **App Name**: nova App Maker

## Core Features:

- Text Input: Users enter a textual description of their desired application.
- AI App Builder: An AI tool analyzes the text input, infers the app's required features and functionality, and generates the app's UI code, including basic function calls that accomplish what was described.
- App Preview: Show a preview of the generated app UI and its functionality within the App from Text.
- App Export: Give the option to download the generated Nextjs app as a single HTML file, with all required code packaged inline, and necessary javascript libraries included.

## Style Guidelines:

- Primary color: Soft Blue (#A7C4BC), inspired by the calming feeling of technology, to reflect AI generation, without being cliché
- Background color: Light gray (#F0F2F5), nearly the same hue as the primary, appropriate for a light scheme.
- Accent color: Seafoam (#84B173), a color analogous to soft blue, different enough in saturation and brightness to pop.
- Body and headline font: 'Inter' sans-serif, suitable for any length of text.
- Code font: 'Source Code Pro' for any displayed code snippets.
- Minimalist, line-based icons for representing actions.
- Subtle transitions for preview updates.
